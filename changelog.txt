Rigacar - Changelog
====================

Version 1.0.4:
- Added interactive "Car Parts Setup" UI panel in the 3D View Sidebar (N-panel -> Rigacar) with object pickers / eyedroppers for Body, Wheels (FL, FR, BL, BR), and Brakes.
- Added "Auto-Detect Parts" operator with smart name and spatial geometry heuristics to automatically identify and assign vehicle parts from selection or scene.
- Added one-click "Create Rig from Chosen Parts" and "Create & Generate Animation Rig" operators with automatic mesh parenting and exact bone dimension snapping.
- Added "Snap Bones to Chosen Parts" and "Attach Parts to Rig" utilities for active armatures.
- Added full verified compatibility with Blender 5.1.2.
- Fixed blender_manifest.toml schema validation errors in Blender 5.1 (tagline character limits, permissions type, set blender_version_min = "5.0.0").
- Restored bl_info dictionary in __init__.py for backward compatibility with classic add-on workflows.
- Fixed AttributeError: 'OBJECT_OT_armatureCarDeformationRig' object has no attribute 'bones_position' by initializing default_bones_position() in execute() when invoked without dialog.
- Hardened create_constraint_influence_driver() against empty driver fcurve modifiers.
- Made class registration and unregistration idempotent across modules to prevent ValueError / RuntimeError on re-registration.

Version 1.0.3:
- Fixed AttributeError: 'Bone' object has no attribute 'select' by ensuring bone selection/deselection occurs safely in Pose Mode across all Blender 4.0 - 5.2+ API versions.
- Added select_bone() and is_bone_selected() helpers to handle PoseBone and Bone selection abstractions uniformly.

Version 1.0.2:
- Fixed AttributeError: 'Action' object has no attribute 'fcurves' on Blender 5.0 - 5.2+ by adding full support for Slotted Actions and ActionChannelbag API.
- Implemented universal F-Curve lookup, creation, and removal helpers supporting both legacy and modern Blender animation data structures.

Version 1.0.1:
- Updated author and maintainer attribution to "David Gayerie (fix by Mister Guide)".

Version 1.0.0:
- Fully ported and modernized for Blender 5.2+ Extensions system.
- Replaced legacy bl_info with modern blender_manifest.toml format.
- Implemented complete bilingual localization (English & Russian) using bpy.app.translations.
- Fixed Bone Collections management for Blender 4.0 - 5.2+ (prevent duplicate collection errors).
- Fixed variable typo in brake bone assignment (wheel_pose_bone.anme -> wheel_pose_bone.name).
- Modernized custom properties initialization using id_properties_ui.
- Added compatibility handling for bpy_extras.anim_utils.bake_action BakeOptions.
- Safeguarded bone wireframe display flags (show_wire) for modern viewport display pipeline.
